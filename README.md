# Base Scaffolding

This repository contains base scaffolding for new projects in different languages.

## Currently Supported Languages

- C
- C++
- Java

## Tools for other languages that already exist

This lists already written scaffolding tools for other languages. 
As these are already written and do their job reasonably well, they are not included in the repository for now.

- Python: [uv](https://github.com/astral-sh/uv)
- Rust: [cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)

## Usage

Clone the repository and run `./scaffold.sh <language> <project_name>` to scaffold a new project in the specified language.
